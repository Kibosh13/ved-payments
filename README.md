# ВЭД / Расчёты

Одностраничный сайт для команды, консультирующей по международным платежным маршрутам.

## Структура

- `dist/index.html` — страница, стили и клиентская логика.
- `dist/send.php` — обработчик заявок и отправка на рабочую почту.
- `dist/assets/` — графические материалы сайта.
- ветка `main` — исходники проекта.
- ветка `gh-pages` — статическая демонстрация.

## Публикация

Рабочая версия размещается на `https://vedpayhelp.ru/` и отправляет заявки через серверный обработчик. Исходники хранятся в ветке `main`.

Статическая демонстрация в ветке `gh-pages` не содержит серверной отправки и закрыта от индексации с помощью `robots.txt` и метатегов `noindex`.
