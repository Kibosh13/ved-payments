# ВЭД / Расчёты

Статический одностраничный сайт для команды, консультирующей по международным платежным маршрутам.

## Структура

- `dist/index.html` — страница, стили и клиентская логика.
- `dist/assets/` — графические материалы сайта.
- ветка `main` — исходники проекта.
- ветка `gh-pages` — статическая демонстрация.

## Ограничение демонстрации

Форма на GitHub Pages подготавливает и копирует текст заявки. Отправка на email будет подключена после указания адреса получателя и реквизитов оператора персональных данных.

Демонстрационная версия закрыта от индексации с помощью `robots.txt` и метатегов `noindex`.
